# rekursivestudios.com

Plain HTML site, hosted on GitHub Pages.

- `index.html` is the home page with the project cards
- `projects/` has one page per project
- `css/site.css` holds every style for the whole site
- `fonts/` has Sukashi in web format (woff2, for the site only)
- `img/` holds images
- `CNAME` tells GitHub Pages to serve the site at www.rekursivestudios.com

Anything highlighted with a dashed yellow box on the site is a placeholder to fill in
(search the files for `class="todo"`).

To add a project, copy one of the pages in `projects/` and add a matching card to `index.html`.
